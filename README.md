# Лабораторная работа №6

## Тема
Изучение алгоритмов формирования и обработки двумерных массивов, программирование и отладка программ с использованием статических и динамических массивов, а также контейнеров STL.

---

## Задания

### Задание 1 (C++)
- Квадратная матрица чётного размера `N × N` (N > 6), заполненная случайными числами от 0 до 100. Выделение левой верхней четверти, вывод суммы и максимального элемента.
- Прямоугольная матрица `M × N` (M > 5, N > 5), заполненная случайными числами от 1000 до 5000. Вычисление суммы цифр всех элементов в каждой строке, поиск строки с минимальной суммой, вывод её элементов в одномерный динамический массив.
- Клеточный автомат «Жизнь» Джона Конвея на ограниченном поле. Демонстрация устойчивой фигуры «пожиратель» (Eater) с планером и случайного поля. Анимация в консоли с задержкой между поколениями.

### Задание 2 (C++)
- Реализация симметричного шифрования AES-128 в режиме OFB (Output Feedback).
- Поддержка русского и английского текста (UTF-8).
- Генерация случайного ключа и вектора инициализации (IV).
- Вывод всех раундовых ключей и промежуточных состояний State для первого блока.
- PKCS7 паддинг.
- Сохранение ключа и IV в файл.

### Задание 3 (C++ / Rust)
- Решение системы линейных уравнений четвёртого порядка методом Гаусса с выбором главного элемента по столбцу.
- Решение той же системы итерационным методом Зейделя с точностью ε = 10⁻³.
- Приведение к каноническому виду `x = Cx + f`, проверка условия сходимости.
- Вывод таблицы итераций и сравнение результатов.

### Задание 4 (C++ / Rust)
- Приведение бинарного поля к паттерну «рамка» (край — одно значение, внутренность — противоположное).
- Выбор лучшего варианта рамки (меньшее число ходов).
- Жадный алгоритм исправления несовпадающих клеток парами с соседями (справа или снизу).
- Пошаговый вывод промежуточных состояний.
